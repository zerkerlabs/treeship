- **The docs gates cover the whole tree and cannot pass by accident.** The security-claims check scans every docs page, the root `*.md` files and `skills/`, and a claims marker now backs only its own line (or the line it sits above), not a whole paragraph. The SDK check resolves every documented client call, TypeScript module methods and Python client methods alike, against the real sources, and scans `skills/` and `integrations/` too. The command and flag checks take extra roots (`--warn-root`) and scan `skills/`, `integrations/` and the root `*.md`. The https one-liner check is a Python script with an explicit path boundary and a unit test, replacing a `git grep \b` that BSD grep read differently. New findings from the wider scope are reported as warnings until the drift they surface is fixed, then the gates switch to failing (`--strict`, and the roots move out of `--warn-root`).
