- **A receipt's API URL verifies as written.** `treeship verify https://api.treeship.dev/v1/receipt/<id>` and `verifyReceipt()` in `@treeship/verify` both did a blind replace of `/receipt/` with `/v1/receipt/`, so the documented API form became `/v1/v1/receipt/<id>` and a 404. Both now apply one rule: the human page `/receipt/<id>` maps to `/v1/receipt/<id>`, the API path and the site's `/api/receipt/<id>` mirror are kept, the host is never rewritten, a trailing slash is dropped, the query string kept, and a URL that names no receipt is refused instead of fetched. The rule lives in `tests/vectors/receipt-urls.json`, which both test suites run. (0.31.9 full test, CLI-11.)
