- **Changelog entries are one file per change.** A PR now adds `changelog.d/<task-or-topic>.md` instead of editing the `## Unreleased` section of `CHANGELOG.md`, so parallel PRs no longer conflict on every merge. `scripts/release.sh prepare` folds the fragments into a new `## <version> (<date>)` section (`scripts/changelog.py assemble`). The docs changelog page shows pending fragments as its Unreleased section. The `docs-drift` CI job validates fragments and fails a PR that adds bullets to `## Unreleased` directly.
