- **`--format json` always emits JSON.** `doctor`, `package inspect`, `pending`, `declare --show`, `otel status`, `templates` and `version` wrote nothing at all in JSON mode and exited 0, because every line they print goes through a printer call that is a no-op there. Each now emits one document (`doctor`: every check with status, label, detail and suggestion, plus the tallies; `package inspect`: the receipt and its side-effect summary; `pending`: the queue; `declare --show`: the declaration or `found: false`; `otel status`: configuration without the credential; `templates`: the catalogue; `version`: version and implementation). A new test runs every command that answers locally in JSON mode and requires a parseable document, and checks the binary's own command tree (a hidden `__dump-cli`) so a new command must be run or named with a reason. `merkle status`, `checkpoint` and `merkle proof` are the follow-up (their file is changing in another fix). (0.31.9 full test, CLI-10.)
- **`doctor` no longer reports auto-push as enabled.** The `auto_push` setting is a stub (the daemon logs "not implemented"); doctor now warns that it is set but does nothing, and the bundled templates no longer turn it on. (0.31.9 full test, DOC-1.)
