- **Revoking an asserted capability card takes effect.** `revoke-capability` on a card that is not key-bound printed "revoked" and exited 0, but `verify-capability` and `resolve` kept honoring the card: the revocation's signature was checked only against pinned trust roots, and an asserted card's key is the ship's own, unpinned key. A revocation is now verified against the keys this machine trusts, its own keys and the pinned roots, the same set the card itself is verified against, so a self-revocation by the card's key counts whether that key is pinned or local. The revoke output names the authority as "the card's key, the ship default key" for such a card instead of "agent key". (0.31.11 re-test, N-38.)
