- **The preview and certificate pages escape every rendered field.** `preview_template.html` and `certificate_template.html`'s shared `esc()` helper now covers `"` and `'` as well as `&`/`<`/`>`, so a field placed inside a quoted HTML attribute (a capability's `title`, for example) can't end that attribute early. Fields meant to be counts (`authority.checked`/`violations`/`unverified`/`bearer`, an approval grant's `delegation_hops` and `scope.max_uses`) are coerced through the existing `num()` helper before they reach the page, rather than assumed to already be numbers. `timeOf()` (the timestamp formatter used across both pages) now escapes its own output once, at the source, instead of depending on every call site to do it. The render-failure path's error text is escaped too. `receipts/ssn_aab97aefa1f8a48c.treeship/preview.html`, the example package checked into the repo, is regenerated from its own `receipt.json` against the updated template so it matches what ships. Two new tests build a page with an unusual payload in every rendered field and confirm the output never contains an unescaped tag or attribute-breaking quote.
