- **A linked `.treeship/` fails closed for session commands.** The rule that routes session commands to the workspace holding the active session refuses a `.treeship/` directory or a `config.json` beside the session that is a symlink, including a dotfiles-style link to your own checkout; such a workspace falls back to the normal resolution with a clear error rather than being opened through the link. Use `--config` with the real path if you keep `.treeship` behind a link.
