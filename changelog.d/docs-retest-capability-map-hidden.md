- **`capability-map.json` now names hidden commands (row 110).** `gen-capability-map.py` parses the top-level `Command` enum in `packages/cli/src/main.rs` for `#[command(hide = true)]` attributes, converts each variant to its clap kebab-case name (honoring an explicit `name = "..."` override), and probes every one against the built binary (`<cmd> --help`, `probed: true/false`) to add a new `cli_commands_hidden` array (22 entries, all probing clean) alongside the existing `cli_commands` list. A new `HIDDEN_CLI_COMMANDS` list in the script is the hand-maintained, human-reviewed source for what gets probed; a new check (`check_hidden_list_current()`, runs unconditionally, not just under `--check`) fails the moment the source and that list disagree in either direction, so a newly-hidden command needs a person to add it (and, ideally, ship a docs page) rather than the map silently drifting again.
