- **The three canonical-JSON encoders are pinned to each other.** `disclosure`, `merkle::checkpoint` and `statements::invitation` each carry their own copy of `canonical_json_string`, and each one feeds a digest that ends up in a signed artifact. They are the same algorithm written three times, with nothing stopping one from drifting and silently changing a digest that older records were signed over. A parity test now runs every case through all three and a second test pins the encoding byte for byte, including empty members, non-BMP keys and numbers. Test-only; no behaviour changes.
