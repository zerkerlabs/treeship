- **Countersign hints are complete.** `session answer-challenge` and `session join` (text and `countersign_hint` in JSON) name every flag the host needs: `--challenge`, `--challenge-issued-at` and `--challenge-response`, and `--pending <file>` in place of the participant id when the join was written with `--out` for a host on another machine. The host used to learn the missing flags from exit 4.
- **`match --class` and `room create --delegate` validate their arguments.** An unknown class exits 4 before the hub is asked (it used to answer with an empty match set); a delegate that is not an Ed25519 public key exits 4 instead of being sealed into the room.
- **`agents remove` of a card that is not there is an error**, not "removed" with exit 0.
- **A second `init` says what is true.** In a directory with no workspace of its own while a global one exists, the message names the global workspace and the two ways forward instead of "no Treeship workspace here, and the global one is not this directory's".
- **`hub open` on a self-hosted hub opens the hub's own workspace page.** The session token the hub mints stays on the origin that minted it; it used to be pasted into a treeship.dev URL that does not exist for that hub. The hosted hub is unchanged.
- **`init --help` no longer says the key is tied to the machine.** The key is encrypted with a seed file kept beside the keystore and travels with `.treeship/`, as SECURITY.md says.
