- **Nonsense input is refused before anything is signed.** `attest decision --confidence 7.5` was signed and printed as 750%; `attest endorsement --kind bogus`, `attest action --input-digest abc` and `--actor ""`, `session event --meta '{bad'` (silently dropped, where `attest` refused it), `declare --valid-until notatime`, `history --class bogus` and `--since yesterday` (silently matched nothing), a handoff of artifacts that do not exist, and `--format xml` (ran as text) were all accepted. Each is now a usage error (exit 4) with the accepted form in the message: a confidence is 0.0 to 1.0; an endorsement kind is validation, compliance, countersignature or review; a digest is `sha256:` plus 64 hex characters; an actor is a `scheme://name` URI; `--meta` is a JSON object; timestamps are RFC 3339 and `--since` also takes a duration back from now (`30d`, `12h`); `--artifacts` must name artifacts in the store; `--format` is text or json. The contract test pins each. (0.31.9 full test, CLI-14.)
