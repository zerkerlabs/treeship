- **`treeship add claude-code` installs the Claude Code plugin.** It used to write `~/.claude/mcp.json` and report Claude Code as configured, but Claude Code never reads that file (its MCP servers live in `~/.claude.json` and a project's `.mcp.json`, its hooks in `~/.claude/settings.json`). The plugin is the real harness, hooks plus the MCP server, so `add` now runs `claude plugin marketplace add zerkerlabs/treeship` and `claude plugin install treeship@treeship` through the `claude` CLI when it is on PATH and you say yes (or pass `--all`), prints the two commands otherwise, says plainly what it did and did not change, and removes the stale `mcpServers.treeship` entry an earlier version wrote, only when it is exactly that entry. (0.31.9 full test, CLI-16.)
