- **Receipts no longer carry the machine's hostname.** `host_id` was `host_<hostname>` and appeared on every event and in the hosts table, eleven times in a typical receipt, untouched by path redaction. Unset `TREESHIP_HOST_ID`, it is now `host_` plus the first 16 hex characters of a SHA-256 digest of the hostname: stable on one machine, not the name. `TREESHIP_HOST_ID` still names the host outright. (0.31.11 re-test, N-41.)
