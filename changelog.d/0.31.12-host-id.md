- **Receipts no longer carry the machine's hostname.** `host_id` was `host_<hostname>` and appeared on every event and in the hosts table, eleven times in a typical receipt, untouched by path redaction. Unset `TREESHIP_HOST_ID`, it is now a random id minted once per install and kept at `~/.treeship/host_id`: stable on one machine, unrelated to the hostname. (A hostname digest was considered and rejected: with no secret in it, a short list of common machine names reverses it.) `TREESHIP_HOST_ID` still names the host outright, and the propagation context the bridges read gives the same answer. (0.31.11 re-test, N-41.)
