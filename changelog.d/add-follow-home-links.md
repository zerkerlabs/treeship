- **`treeship add` follows your own dotfiles links.** A harness config path under your home that is a symlink (`~/.cursor -> dotfiles/cursor`, `~/.codex/config.toml -> dotfiles/codex.toml`) is now configured where the link points, and the link is kept. Earlier releases skipped such paths with "config path contains a symlink". The project `TREESHIP.md` in the working directory is still not written through a link.
