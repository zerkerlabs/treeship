- **The zk build compiles again, and CI builds every feature the binary tells you to build.** `cargo check -p treeship-cli --features zk` had failed since a refactor dropped an import, while the non-zk stubs told users to rebuild with exactly that flag; CI built only the default features, so nothing noticed. The import is back, two functions that were dead under `--features zk` are gone (`zk_status` duplicated `zk-setup`; `enqueue_proof_job` was an unused wrapper), and a new `feature-matrix` CI job checks `--no-default-features`, `--features zk`, `--features zk-bonsai` and the wasm32 target of core-wasm with warnings denied. Four warnings the wasm32 build had carried (unix-only items not gated to unix) are gated. (0.31.9 full test, CLI-7 and PKG-3.)
