- **`/v1/verify` documented as retired; artifact-id formula corrected (W3-5, DOC-3/DOC-7).** `AGENTS.md`, `PLATFORM.md` and `ONBOARDING.md` described `GET /v1/verify/:id` as a live server-side verifier, including a worked example claiming it "should return a passing ChainResult"; the route has been intentionally retired since before this audit and returns `410` with no verdict -- the hub is transport/index only. Rewrote each mention to say so and point at local verification. Separately, `docs/content/docs/reference/receipt-format.mdx` had the artifact-id truncation backwards: `hex(sha256(PAE_bytes))[..16]` truncates the *hex string* to 16 characters (8 bytes of entropy, the wrong id); the real formula (`packages/core/src/attestation/id.rs`) truncates the 32-byte *digest* to 16 bytes first, then hex-encodes, giving the correct 32-character id. A verifier built from the old formula would compute wrong ids for every artifact. Verified the fix against the Rust implementation's own doctest (id length 36 = `art_` + 32 hex chars) before writing it.
