- **`keys rotate` updates the default key everywhere.** The keystore promoted the successor but `config.json` kept naming the predecessor as `default_key_id`, so `hub attach` after a rotation bound the old key, which stopped being valid when the grace window closed. Rotating with the default promotion now writes the successor into `config.json` too, and the JSON output reports `config_default_key_id` and `config_updated`; `--no-default` leaves both alone. `hub attach` also records `created_at` as an RFC 3339 timestamp instead of `"<epoch>Z"`.
