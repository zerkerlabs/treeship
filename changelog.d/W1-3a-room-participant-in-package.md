- **A countersigned room participant verifies inside its package.** The joining agent and the host sign a participant's canonical bytes, not the DSSE envelope, so `package verify` checked it like any other artifact and failed every honest room (`treeship verify` passed the same artifact). The package verifier now checks a participant against the invitation it redeems, which must be sealed in the same package and signed by a key the package carries that is the invitation's issuer: both signatures over the canonical bytes, the same session, and the id re-derived from the pending envelope. A missing or failing invitation fails the row; it never falls back to the generic check. The host's key, not the joiner's, is what `signer_trust` judges.
