- **Session commands record into the session's own workspace.** With `TREESHIP_CONFIG` exported to another store, the Claude Code plugin's hooks appended events to the project's session but sent the signed approvals and attestations (`attest approval`, `attest receipt --chain`, `halt list`, `judge`) to the other store, so the receipt showed nothing captured. Every session command and every command that signs into a session now uses the workspace whose `config.json` sits beside the active `session.json`, opened with the same discovery checks as the shell hook; `--config` still wins, and `TREESHIP_CONFIG` applies when no active session is found. The session walk stops at the home directory, like the shell hook's. (0.31.11 re-test, N-12 / N-36.)
