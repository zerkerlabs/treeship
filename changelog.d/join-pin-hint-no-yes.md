- **`session join` no longer suggests trusting the host's key blind.** When the invitation's issuer is not pinned under `session_host`, the hint now says to confirm the key with the host out of band first and offers `treeship trust add … --kind session_host` without `--yes`, the same rule `merkle verify` follows for an unpinned checkpoint signer. A copy-paste that silently trusts a key taken from the thing being checked is never offered.
