- **The content layer: the bytes behind a digest.** A step receipt commits to its output by digest, not by value, which is what lets a trace be handed to someone who should not see the data -- and also what left a reader holding a commitment to something nobody could open. Packages may now carry the bytes in `content/`, one file per blob, each named by the SHA-256 of its own contents. A blob is bound to the trace because a signed statement in the package already names its digest, and that is the entire binding: nothing new is signed, and `treeship package content add` refuses bytes the trace does not name, so attaching content long after sealing and dropping it before sharing each leave every signature, the Merkle root and the chain exactly as they were. `treeship package content ls` lists what the trace commits to and how much of it is openable here; `get` recomputes the hash before it hands anything over and writes to stdout by default, so the bytes can be piped into `shasum -a 256` and checked by someone who trusts neither the package nor this binary; `drop` removes bytes and keeps the commitment to them.
- **`package verify` gains a `content` row, which fails on two things.** A blob whose bytes do not hash to the name it is filed under -- that is a substitution no signature would catch, because nothing signed covers the file -- and a blob no signed statement names, which is an attachment the trace does not account for rather than part of it. A reader who finds bytes inside a package reads them as part of it, so that one fails rather than warns. A trace that commits to more than it carries is not a failure: content is optional and dropping it is supported, so the row reports the ratio and leaves the judgement to the reader. Packages with no `content/` directory get no row at all.
- **`treeship package redact` now takes a withheld step's content with it.** The digest that justified a blob lives inside the envelope being withheld, so leaving the bytes behind would disclose exactly what was meant to be withheld and fail the copy's own `content` row. The surviving digests are recomputed from what is left in the copy rather than from the withheld envelopes, so a digest two steps both name survives the withholding of one of them.
