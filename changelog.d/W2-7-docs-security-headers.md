- **Security headers added to docs.treeship.dev (W2-7).** `docs/next.config.mjs` now sends `Content-Security-Policy`, `X-Frame-Options: DENY`, and `Strict-Transport-Security: max-age=63072000; includeSubDomains`, matching the header set `treeship.dev` PR #121 shipped for `www`. The CSP is narrowed to what the docs site actually loads: self-hosted fonts (no Google Fonts exception), same-origin fumadocs search via `/api/search` (covered by `default-src 'self'`), and Google Analytics (`googletagmanager.com` / `google-analytics.com`) in `script-src`/`img-src`/`connect-src`. No WASM allowance -- that's only needed on the main site's `/verify` page. Verified with a production build, a local `next start`, and a headless crawl of the main page types plus the search flow: zero CSP violations, GA and search both load over `'self'`/the allow-listed GA hosts.
