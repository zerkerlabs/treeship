- **Workspace writes no longer follow links.** Every file Treeship writes under a workspace, a keystore, a store or a session, and every file it writes into the working directory, is created without following a symbolic link at the path or on the way to it, and temporary files are created exclusively under random names. A workspace, keystore or store directory that is itself a link is refused with a message saying how to point `--config` at the real path.
