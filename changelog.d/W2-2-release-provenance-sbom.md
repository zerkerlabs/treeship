- **Release binaries carry signed build provenance and an SBOM (W2-2, SUP-3).** The release job now attests SLSA build provenance, signed through Sigstore with GitHub's OIDC token, for the four binaries, `SHA256SUMS` and a new `treeship-sbom.spdx.json` (an SPDX SBOM of the Rust workspace's `Cargo.lock`, a superset of what the CLI links), and attaches the SBOM to the release. Attestation runs before the release is created, so a signing failure publishes nothing. Check a download with `gh attestation verify treeship-<platform> --repo zerkerlabs/treeship`.
