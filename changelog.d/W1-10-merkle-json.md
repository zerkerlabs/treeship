- **`merkle status`, `checkpoint` and `merkle proof` emit JSON in `--format json`.** `merkle status` wrote 0 bytes; `checkpoint` and `merkle proof` wrote the root shortened to 16 hex characters and numbers as strings, so a script could neither compare a root nor read a size. Each now emits one document with the whole `sha256:` root and real numbers (`tree_size`, `index`, `height`, `leaf_index`), and the JSON contract test runs all three instead of skipping them.
